What this build demonstrates

Actual browser WASM face inference → conservative semantic reconstruction → an open-weight local LLM → a revision-bound browser action. The server reasons over the layout data; this build does not claim pixel-reading VLM inference. Closed shadow roots, unknown text and raster content remain excluded. This trades visual detail for a smaller privacy boundary.

Face detection can miss faces. Its result never grants permission to transmit original image pixels. Layout itself can still reveal page structure; the preview makes that residual exposure inspectable.
