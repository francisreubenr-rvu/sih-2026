# WebPII synthetic test images

Source dataset: WebPII/webpii, revision6d3317721b72bde719a361c564ceaf1fbded3a8e, https://huggingface.co/datasets/WebPII/webpii . Root dataset card declares Apache-2.0. License text and attribution are retained in Raw/datasets/webpii-test100/. Images are viewer-delivered JPEG reproductions with .png baseline filenames; original bytes are unchanged. The manifest retains exact row IDs, metadata and hashes. Temporary signed delivery URLs are excluded.

These synthetic UI reproductions are evaluation fixtures. Their page brands, images and styles are not endorsements, partnerships or original Sightline design assets. This folder is not included in the public landing page. The detector and scorer receive data through separate paths; annotations are never model inputs.
