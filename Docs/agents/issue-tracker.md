# Local issue tracking

PLAN.md preserves the full user objective. ROAST.md tracks concrete implementation findings and fixes. Feature PRDs/issues may use `.scratch/<feature>/PRD.md` and `.scratch/<feature>/issues/<NN>-<slug>.md` with a Status line. No external issue/comment messages are needed for this autonomous build.

This reversible default follows the user's instruction to proceed without clarification. GitHub remains the authorized source/publication remote. A future explicit request can switch issue management to GitHub.
