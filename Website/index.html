LOCAL ENGINEERING PROTOTYPE

Run it on your machine.

This website is static. The working demo needs the repository, Node.js 22+ and a local Ollama model server.

  1. Clone the repository and install the prototype dependencies.
  2. Start Ollama and install qwen2.5:7b-instruct if needed.
  3. Start Sightline, then open the local workspace below.
git clone https://github.com/francisreubenr-rvu/sih-2026.git
cd sih-2026/Prototype
npm ci
node ../scripts/build-prototype.mjs
# Run Ollama in a separate terminal: ollama serve
ollama pull qwen2.5:7b-instruct
npm start
