What leaves this device: semantic scene fields only (allowlisted control labels, geometry, opaque region kinds). What stays local: raw pixels, screenshots, field values, URLs, and free text. A smaller payload is not a guarantee of anonymity — layout can still reveal context.

Three paths.
Separate SLOs.

Architect split: Fast, Score, Reason. DigiLocker-inspired trust chrome is a UX trust pattern only — not DigiLocker partnership, APIs, credentials, or custody. Select a path for boundary, timing policy, and limits.

Fast  : capture → detect → mask → privacy review   (no LLM; timing ≠ G11)
Score : local heuristic risk after Fast protect    (partial / official null)
Reason: Ollama/Qwen plan → human confirm           (outside <200 ms today)

FAST PATH · ON DEVICE

SLO: local protect diagnostic only. Fast ≠ G11. G11 remains fail until Reason-inclusive p95 <200 ms at n≥100.

LOCAL ENGINEERING PROTOTYPE

Run it on your machine.

This website is static. The working demo needs the repository and Node.js 22+. Privacy-only Fast Capture & protect runs without Ollama; the Reason path needs a local Ollama model when you want planner suggestions.

  1. Clone the repository and install the prototype dependencies.
  2. Start Dhristi, then open the local workspace and try Capture & protect (Fast path — no LLM).
  3. Optional Reason path: start Ollama and pull qwen2.5:7b-instruct before asking the local model.
git clone https://github.com/francisreubenr-rvu/sih-2026.git
cd sih-2026/Prototype
npm ci
node ../scripts/build-prototype.mjs
npm start
# Optional Reason path (separate terminal):
# ollama serve
# ollama pull qwen2.5:7b-instruct
