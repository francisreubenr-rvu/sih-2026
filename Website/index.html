The boundary

Useful context. A smaller exposure.

A browser agent needs enough information to help. It does not need an unrestricted copy of your screen.

On your device

Original screen

  • Screenshot pixels
  • Names and field values
  • Images and unknown text

Excluded from the request.

Approved context

Protected scene

  • Control labels from an allowlist
  • Position and size
  • Opaque region types

Reviewed before model processing.

What leaves this device: semantic scene fields only (allowlisted control labels, geometry, opaque region kinds). What stays local: raw pixels, screenshots, field values, URLs, and free text. A smaller payload is not a guarantee of anonymity; layout can still reveal context.

How it works · shipping build

Five stages. One machine.

The extension side panel and the local Warden service run every step on your computer. Only the protected scene reaches the planner.

  1. 01

    Perceive

    The extension scans the page's controls and captures the visible tab. Personal fields are painted over in the capture before anything else sees it.

    Browser
  2. 02

    Strip

    Pattern rules and a GLiNER model replace personal values with tokens such as EMAIL#1. Spans it is unsure about stop the run and ask you.

    Warden · 127.0.0.1:8756
  3. 03

    Plan

    A local model proposes the next action from the tokenized task and a sanitized page outline. No screenshot, no field values.

    Ollama · 127.0.0.1:11434
  4. 04

    Validate

    Deterministic checks, then the extension's own gate. Anything beyond a reversible or navigational step waits for your confirmation.

    Warden + extension
  5. 05

    Execute

    The extension acts only on the exact element it scanned, after checking that it is still visible and still means the same thing.

    Browser

Status: the side panel and Warden are covered by unit and browser tests, but have not yet run end to end against a live Warden and Ollama. The full flow currently takes seconds, so the <200 ms gate (G11) stays fail.

Local engineering prototype

Run it on your machine.

This website is static. The working demo needs the repository and Node.js 22+. Privacy-only Fast Capture & protect runs without Ollama; the Reason path needs a local Ollama model when you want planner suggestions.

  1. Clone the repository and install the prototype dependencies.
  2. Start Dhristi, then open the local workspace and try Capture & protect (Fast path, no LLM).
  3. Optional Reason path: start Ollama and pull qwen2.5:7b-instruct before asking the local model.
git clone https://github.com/francisreubenr-rvu/sih-2026.git
cd sih-2026/Prototype
npm ci
node ../scripts/build-prototype.mjs
npm start
# Optional Reason path (separate terminal):
# ollama serve
# ollama pull qwen2.5:7b-instruct
