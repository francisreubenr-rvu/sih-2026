01 / The approach

Understand more.
Expose less.

Useful assistance starts with context.
It shouldn’t start with collecting everything.

  1. 01

    See the page

    Read the page and its controls locally, so the browser has the context it needs.

  2. 02

    Replace details

    The local filter replaces detected personal values with tokens. Uncertain detections can ask for your input.

  3. 03

    Plan with context

    A planner uses the sanitized task, page context and tokens to propose the next browser action.

  4. 04

    You stay in control

    The browser checks the action locally and asks for confirmation before actions it classifies as risky.

not a promise to take on faith.

TO THE PLANNER

A smaller context.

  • The sanitized task and page context
